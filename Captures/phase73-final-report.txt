PHASE 73 — RIGID CHAIN-TO-TARGET GROUP MATCH
============================================

Pre-change analysis
-------------------
1. Orchestration
   - Auto-match: LevelManager.ResolveAlreadyAlignedMatchQueue
     → CollectAlignedMovementGroups → PlayResolvedMovementGroup
     → PlayMatchingSubsetAlignedMatch (already rigid when Actions.Count >= 2)
   - Player drag: EnterMatchingTargetBody → EnterChainPartialMatch
     → MatchFocusedChainCell → (was) one-cell PlayChainCellNestEntry

2. Why members traveled sequentially
   - CollectChainFocusedMatch called KeepOnlyNearestMatch for non-nested
     multi-cell blocks, collapsing N matches to 1 traveler.
   - Nested blocks already used KeepNestedSameTranslationMatches + subset
     play (Phase 71B); plain chains did not.

3. Existing data identifying members / targets
   - nestCellIndices / nestTargets / nestTargetWorlds
   - AlignedMatchAction (Subject, CellIndex, CellWorld, NestTo)
   - AlignedMovementGroup (Subject, Translation, Actions)
   - ShapeMatch.AreMatchingLayers for correspondence

4. Common rigid translation
   - translation = NestTo - CellWorld for focus-nearest match
   - KeepSameTranslationMatches retains every cell with that translation
   - CanTranslateMatchingSubset + axis/fixed-direction gate before travel
   - AnimateMatchingSubsetNestEntry: shared progress, position[i] = start[i] + delta

Implementation (presentation only — matching not rewritten)

6. Methods changed (BlockMover.cs)

     PlayMatchingSubsetAlignedMatch (nested and non-nested)

     non-occupyingOnly multi-cell; infer one axis-aligned translation
     from focus then collect full footprint under that translation
   - KeepSameTranslationMatches — renamed/generalized from
     KeepNestedSameTranslationMatches (alias retained)
   - TryBuildNestedSubsetGroup — reject diagonal / fixed-direction-illegal
     rigid hops

   - TryMoveBlock / occupancy / nestTo / finger drag unchanged
   - Auto-match CollectAlignedMatchActions / BuildAlignedMovementGroups unchanged
   - ConsumeAndRebuild / VFX / nested extraction reuse existing subset path

8. Mixed shapes
   - Collection uses per-cell GetActiveIdentity + AreMatchingLayers
   - No assumption of identical shapes

9. Arbitrary chain length
   - No hardcoded N; Actions.Count / CellCount drive the subset
