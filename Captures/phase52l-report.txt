PHASE 52L-FIX — Particle Velocity Curve Mode
==================================================
Error: "Particle Velocity curves must all be in the same mode"

Source: BoardVfx3D.SpawnBurst — VelocityOverLifetimeModule for:
- BurstFeel.IceMelt
- BurstFeel.ShutterOpen

Mixed modes (invalid):
- Y set via MinMaxCurve(min, max) → TwoConstants
- X / Z left at module defaults → Constant
Unity rejects mixed Constant + TwoConstants on the same module.

Fix (common mode = TwoConstants on X/Y/Z):
- IceMelt:  x=(0,0)  y=(0.08s, 0.22s)  z=(0,0)
- Shutter:  x=(0,0)  y=(0.04s, 0.14s)  z=(0,0)
Upward float ranges preserved. No other VFX redesign.

MatchEffect.cs: no ParticleSystem velocity (not involved).
