## Interaction effects added

### Tap / select (PieceView3D + Block.ShowDragSelection)
- PlayTapFeedback: micro lift pulse on visualRoot
  - peak local Y ≈ 0.055 → settle to held lift
  - durations: 0.05s up + 0.07s down (ease-out cubic)
- SetHeldBlend (mesh/visualRoot only — NOT root footprint scale):
  - scale peak: 1.04 (InteractionScalePeak)
  - lift: 0.045 world-local on visualRoot (InteractionLiftLocal)
  - soft contact shadow radius boost: +0.10 * heldBlend
- Block dragSelectScale default: 1.02 → 1.04
- Block dragSelectDuration default: 0.07 → 0.10
- Held blend applied to all world views (primary + chain extras)
- Nested inner localPosition follows visualRoot (including micro-lift) so outer/inner stay aligned

### Drag start
- Existing WorldPieceMotion pickup (PickupDuration=0.08, CarryScaleBoost=0.05) unchanged
- Before first hop creates WorldPieceMotion, held scale/lift provides immediate pickup feel
- When carry PresentationLift > 0.02, interactionLiftLocal clears so lifts do not stack

### Drag follow / release
- Destination calculation unchanged (BoardCellDestinationHighlight3D / BlockMover)
- Release: HideDragSelection eases held blend/scale back; existing hop/settle path remains Phase 52E

### Destination highlight polish
- Subtle breath scale: amplitude 0.028, ~0.55 Hz (LateUpdate)
- Activation / cell selection / validity rules unchanged

### Invalid interaction
- Settled block press: PlayInvalidInteractionFeedback → PlayInvalidNudge
  - mesh scale 1.00 → 0.97 → 1.00 over 0.10s
- Does not consume charges or alter input routing
