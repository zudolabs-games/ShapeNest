YES, simultaneously into the Editor Game view composite:

Scene view shows Board3D only (no Overlay) → red 3D diamonds.

and/or stale camera pixels + UI.

  (Captures/72j-gv-boardui-off.png)

-------------------------------------
Not proven as a single live green MeshRenderer (greenDiamondMats=0).

Two contributing facts:

A) Legacy UI Board is active and owns Game-view piece visibility in the
   disable test (empty board when UI Board off).

B) Prior 72I: Game view RT had lime diamond OFFSET on red while
   BoardCamera.Render was pure red; forcing BoardCamera into Game RT
   cleared lime. That is camera-RT staleness / composite mismatch,
   not a second 3D mesh.

UI Image.color scan found no lime tint; BlockDiamond UI Images were
disabled. Green block-shaped pixels in older Game captures are therefore
either:
  - stale BoardCamera/Game RT pixels from mid-peel (green 3D outer), and/or
  - a UI sprite path not caught by Image.color (needs sprite-pixel check
    on any re-enabled BlockDiamond during the peel frame)
