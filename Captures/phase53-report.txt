==================================================
SHUFFLE IMPLEMENTATION
==================================================
ShuffleBooster (IBooster):
- Idle / Executing phases (no selection phase)
- Collects eligible non-settled Blocks not moving/dragging and not under closed shutter
- Builds random placement plan (max 48 attempts) with footprint validation
- Rejects identical arrangement and immediate nest matches (HasNestMatch)
- Applies occupancy first (Unregister → TryRegister → SetGridPosition preserveWorldPresentation)
- Animates each cell PieceView3D via WorldPieceMotion.AnimateHop
- Consumes exactly 1 charge only after valid plan accepted (before animation)
- Resets coroutine/state on disable and via BoosterManager.ResetAll on level load/restart

==================================================
SHUFFLE UNIT DEFINITION
==================================================
One gameplay Block object (including multi-cell chains and nested shape-in-shape cells).
Relative local cell geometry preserved; entire unit translated to a new valid anchor.

==================================================
VALID DESTINATION LOGIC
==================================================
Uses BoardManager APIs only:
- IsInsideBoard
- DoesFootprintTouchClosedShutter
- FootprintTouchesTarget (no nest cells)
- HasNestMatch (avoid immediate auto-match)
- Occupancy simulation via HashSet (static blocked cells + non-shuffle occupants + placed units)
