PHASE 79L AUDIT (pre-fix)
=========================

Root cause candidates identified:

1. Target.transform.position is Canvas/UI space (e.g. 360,1420,0), NOT World3D.
   TargetDirectionHintEffect.ResolveTargetWorld() fell back to target.transform.position
   when WorldView was missing — curves spawn off the board camera → "hint not appearing".

2. Multi-cell nests (Campaign targets are cells=2..3 with ExtraWorldViews):
   Hint always used WorldView (anchor) PickWorldCenter, ignoring the CollectNestMatches
   matching world cell. For matches on an extra nest cell, stroke placement can be wrong
   / look absent at the cell the player is aiming at.

3. Accent color used nest.GridPosition / RequiredShape only — not the matching cell's
   GetRequiredIdentityAtWorld from CollectNestMatches. Nested/multi-layer accents can
   disagree with the cell gameplay matched.

4. Trigger itself uses HasNestMatch + CollectNestMatches (correct, no shape switch).
   No shape hard-coding found in 79K. Coverage gap is resolution/placement, not
   "if Circle then skip".

5. At Campaign_43 rest layout only Triangle has a reachable one-away path without hops;
   other shapes need travel — real-drag coverage must hop or start closer.

Matching source: BoardManager.HasNestMatch / CollectNestMatches / ShapeMatch.AreMatchingLayers
Target resolution fix: GridSpace3D.GridToWorld(matchWorldCell) + PieceView when available
