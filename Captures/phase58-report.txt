Audit:
- Pointer/touch: InputManager (mouse + Input System touch)
- Block pick: BoardInput3D physics raycast → PieceView3D → Block
- Direction: InputManager cardinal from screen delta (no diagonals)
- Grid commit: BlockMover.DragRoutine → BoardManager.TryMoveBlock → Block.SetGridPosition
- Chains: one Block with ShapeCellData local offsets; TryMoveBlock translates all cells
- Fixed direction: Block.MoveDirection + BlockMover.IsDirectionAllowed
- Boosters: BoosterManager.IsAnySelecting intercepts InputManager before drag

Implementation:
- Drag threshold: 28 screen pixels
- First grid hop: max(28px, 0.55 × on-screen cell)
- Further hops: +1 cell of on-screen travel each
- Mapping: 3D cell projection via BoardCamera3D + GridSpace3D (not UI RectTransform)
- Release: EndDrag; piece stays on last valid GridPosition
